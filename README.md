## 📌 Project Overview

This project focuses on developing fundamental Python data analysis skills using **NumPy and Pandas**. It covers array creation, numerical computations, data manipulation, indexing, slicing, and data exploration through practical exercises.

The assignment uses temperature records, student marks, and transaction datasets to understand how Python libraries simplify data analysis.

## 🎯 Project Objectives

- Understand NumPy arrays and their properties.
- Perform numerical calculations and array operations.
- Learn Pandas Series creation and manipulation.
- Explore DataFrames and perform data filtering.
- Apply indexing, slicing, and grouping techniques.
- Develop basic data analysis skills using Python.

## 📂 Project Structure

### 1. NumPy Array Operations
Worked with two weeks of temperature data to perform:

- 1D and 2D array creation
- Array shape, size, and data type inspection
- Celsius to Fahrenheit conversion
- Maximum, minimum, and mean calculations
- Array indexing and slicing
- Extracting weekly and weekend temperatures

### 2. Pandas Series
Created and manipulated student marks using:

- Series creation with custom index labels
- Integer-based indexing using `iloc`
- Label-based indexing using `loc`
- Boolean filtering
- Updating and deleting Series elements
- CGPA calculation

### 3. Pandas DataFrame
Created a transaction dataset and performed:

- DataFrame creation
- Data exploration using `head()`, `tail()`, `shape`, and `dtypes`
- Column selection and filtering
- Value counts and unique value identification
- Grouping data using `groupby()`
- Calculating average transaction amounts by region
- Adding, updating, and deleting columns and rows

## 💡 Key Concepts Learned

- Array manipulation
- Data indexing and slicing
- Boolean masking
- Data selection and filtering
- Statistical operations
- Data grouping and aggregation
- DataFrame manipulation
